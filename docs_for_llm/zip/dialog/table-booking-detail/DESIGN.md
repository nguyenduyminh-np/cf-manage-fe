# Design System Documentation

## Theme Overview

This document outlines the core aesthetic and functional principles of our design system. It is automatically synchronized with our design tokens to ensure consistency.

### Color Palette

Our color palette is built around a `light` mode, ensuring a bright and accessible user experience. The primary brand color is a rich `#4E342E` (a deep brown), providing a strong and sophisticated base for interactive elements. A vibrant `#2E7D32` (a forest green) serves as the secondary color, offering a refreshing contrast for supporting UI elements. An accent of `#D4A373` (a soft, earthy orange) is used for highlights and decorative touches, adding warmth. Our neutral base for backgrounds and surfaces is a clean `#FDFBF7`.

### Typography

Our typographic system is designed for clarity and readability across all content.
*   **Headlines** use `manrope`, a modern sans-serif typeface known for its geometric clarity and versatility, ensuring impactful headings.
*   **Body text** utilizes `workSans`, a highly legible sans-serif font that performs well in various sizes and contexts, making long-form content comfortable to read.
*   **Labels** also employ `workSans`, maintaining consistency and ensuring that interactive elements are clearly communicated.

### Shape and Form

The system uses a `roundedness` level of `1`, which provides subtle rounding to UI elements. This introduces a touch of softness without losing a sense of structure and modernity.

### Spacing

A `spacing` value of `2` dictates the layout and density of our UI. This `normal` spacing provides a balanced and comfortable visual experience, allowing elements to breathe without feeling overly sparse or cramped.
